# Modern AI Chatbot UI

A clean, responsive ChatGPT clone built for easy deployment on static web hosting platforms (GitHub Pages, Vercel, Netlify) or running directly inside the browser.

## Repository Structure

* `index.html` - Main HTML entry point linking CDNs and project files.
* `style.css` - Custom styles for animations, typing cursors, and scrollbars.
* `app.js` - React application handling chat logic, state, and streaming API responses.

## Setup Instructions

1. Save `index.html`, `style.css`, `app.js`, and `README.md` into the same directory.
2. Commit and push the files to your GitHub repository.
3. Enable GitHub Pages under **Settings** -> **Pages** -> **Branch: main**.
